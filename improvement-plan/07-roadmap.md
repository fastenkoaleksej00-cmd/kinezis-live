## Ранбук: применение одного пункта
1. Резервная копия базы (если пункт содержит SQL).
2. Применить патч или SQL.
3. `npm run typecheck && npm run lint` и сборка.
4. Коммит, деплой на Vercel, проверка на телефоне по чек-листу из `06`.
5. Отметка в `PROGRESS.md`.
