# 10 — Нативная iOS-сборка и требования App Store (круг 2)

Состояние: оболочка Capacitor в `ios/` загружает сайт `https://kinezis-live.vercel.app` (`server.url`). Xcode на компьютере не установлен, сборка не проверялась. Ниже — что потребует ревью Apple (App Store Review Guidelines) и что уже готово.

## Риски отклонения
| Правило | Что требует | Наше состояние | Что сделать |
|---|---|---|---|
| 4.2 Minimum Functionality | приложение не должно быть просто обёрткой сайта | оболочка загружает сайт | добавить нативное: HealthKit, локальные уведомления, виджеты, тактильная отдача, офлайн-экран; без этого высокий риск отклонения |
| 3.1.1 In-App Purchase | цифровые подписки внутри iOS — только через IAP | Premium без оплаты | в iOS-сборке оплата Premium через StoreKit (RevenueCat упрощает, бесплатно до $2.5k/мес выручки); на вебе — Stripe |
| 3.1.3 / 3.1.1 физические товары | товары и партнёрские ссылки можно продавать вне IAP | магазин по внешним ссылкам | соответствует |
| 1.2 User-Generated Content | фильтр, жалобы, **блокировка пользователей**, контакт для обращений | жалобы и модерация есть, блокировки нет | добавить «Заблокировать» (сообщество, этап 2) и контакт `NEXT_PUBLIC_CONTACT_EMAIL` |
| 5.1.1(v) удаление аккаунта | удаление внутри приложения | есть (`delete_my_account`) | соответствует |
| 4.8 Sign in with Apple | обязательно, если есть вход через Google/соцсети | вход Google выключен флагом | если включать Google на iOS — добавить Sign in with Apple |
| 1.4.1 медицинские утверждения | не обещать лечение, не измерять показатели без подтверждения | формулировки «профилактика, восстановление через движение», уровни доказательности | соответствует; не добавлять «лечит» в описание в магазине |
| 5.1.3 HealthKit | данные здоровья только для здоровья, без рекламы и iCloud | мост ещё не сделан | при подключении: строки разрешений, не хранить в общем облаке без согласия |
| 2.3 / 5.1.2 приватность | анкета «Privacy Nutrition Label», трекинг | YouTube-плеер может ставить cookies после нажатия | указать в анкете «Данные, связанные с вами: контакты, контент, здоровье (если HealthKit)»; трекинга нет |
| Встраивание YouTube в WebView | `playsinline`, разрешить inline-медиа | параметр `playsinline=1` уже есть | в `capacitor.config.ts` для iOS: `allowsInlineMediaPlayback` проверить при первой сборке |

## Минимальный набор для первой отправки
1. Xcode, Apple Developer ($99/год), подпись, иконки и экраны запуска (иконки уже сгенерированы в `mobile/assets`).
2. Нативное: локальные уведомления-напоминания (`@capacitor/local-notifications`), тактильная отдача, офлайн-экран.
3. Блокировка пользователей в сообществе.
4. Оплата Premium через StoreKit или отложить Premium в iOS-версии (показывать «доступно на сайте» нельзя — правило 3.1.1 запрещает уводить на внешнюю оплату цифрового контента, кроме исключений для «reader»-приложений).
5. Заполненные политика, условия, контакт, анкета приватности.

## Оценка
Без пунктов 2–3 вероятность отклонения по 4.2 и 1.2 высокая. С ними — типичная фитнес-платформа, проходит ревью за 1–3 итерации.
