# 09 — Путь участника по шагам (круг 2)

Проход по коду, как это видит новый человек. Ничего не изменено.

| Шаг | Что происходит | Оценка |
|---|---|---|
| 1. Первый запуск | 6 слайдов, язык, тема | хорошо |
| 2. Главная гостем | быстрый доступ, магазин, занятие дня, лента | хорошо, длинная (см. `04` U5) |
| 3. Регистрация | почта + пароль, подтверждение выключено | P0 включить (`03` S5) |
| 4. Первая тренировка | библиотека → занятие → видео | см. M1 |
| 5. Прогресс | кольца недели, цель | см. M1 |
| 6. Сообщество | «+» → поделиться / вопрос | хорошо |
| 7. Возврат на следующий день | нет напоминаний | см. M3 |

### M1. Досмотренное видео не засчитывается в активность — P1, S
- **Проблема.** Плеер (наш и YouTube) отмечает видео завершённым в локальном прогрессе, но в журнал активности, от которого зависят кольца недели, цель, серия и челленджи, запись попадает только по кнопке «Я позанимался» на странице занятия (`LogActivityButton`). Человек досмотрел 20 минут, а кольца не сдвинулись — это главный момент разочарования в фитнес-приложениях.
- **Решение.** Когда плеер сообщает о завершении (≥ 95 %), показать прямо под видео карточку «Готово! Засчитать занятие?» с одной кнопкой (без автоматической записи, чтобы не засчитывать случайную перемотку). Для вошедших — запись в `activity_log`, конфетти уже есть (`pop-in`).
- **Польза.** Кольца и серия начинают работать сами — главный механизм возврата (как «Кольца активности» Apple).
- **Риск.** Низкий.

### M2. Гость не понимает, что теряет без аккаунта — P2, S
- Избранное и прогресс гостя живут на устройстве, но об этом сказано только в профиле. На моменте первого «сохранить» или «засчитать» — мягкая подсказка «Войдите, чтобы прогресс не потерялся», не блокирующая действие.

### M3. Нет причины вернуться завтра — P1, L
- Напоминания настраиваются, но ничего не отправляется (пуш не подключён). Шаги: (1) веб-пуш для установленного PWA (Android сразу, iOS 16.4+ после «На экран Домой»); (2) нативные уведомления в iOS-сборке; (3) ежедневная «практика дня» в одно касание из уведомления.

### M4. Первая неделя без сценария — P2, M
- После регистрации человек видит всё сразу. Предложение: «Первые 7 дней» — короткая программа из существующих материалов (день 1 — дыхание 3 мин, день 2 — йога 15 мин из серии Юлии, день 3 — карта тела и упражнение для выбранной зоны…). Технически — обычная программа (`kind = program`), плюс карточка на Главной для новых аккаунтов.

### M5. Выход из воронки на Premium — P2, информация
- Баннер Premium есть, оплаты нет (ждёт юрлица). До запуска оплаты показывать интерес-форму, как сейчас; после — пробный период 7 дней (стандарт App Store и рынка).
