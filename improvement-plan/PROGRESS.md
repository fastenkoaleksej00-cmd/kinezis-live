# PROGRESS — KINEZIS LIVE improvement plan

Режим: только анализ и подготовка. Код приложения, база и рабочая версия **не изменялись**.
Патчи лежат в `patches/`, SQL в `sql/` (не применён), примеры тестов в `tests/`.

## Возможности среды (проверено 2026-10-16)
- Работа идёт внутри одного ответа ассистента; после завершения ответа агент останавливается до следующего сообщения владельца. Таймер «проснуться» доступен только в режиме `/loop`, сейчас он не включён.
- Файлы на диске сохраняются сразу и переживают сессию. Продолжение: написать «продолжай по PROGRESS.md».
- Длинный разговор автоматически сжимается; этот файл — источник правды о том, что сделано.
- Сеть ограничена песочницей; сборка проверяется с локальной заглушкой шрифтов.
