# Apple Health, Apple Watch и данные здоровья: план интеграции

## Что работает сейчас

- Раздел «Моё здоровье» (`/health`): рост, дата рождения, цель, уровень активности, опыт; история измерений веса и талии с датами; графики за неделю, месяц, 3 месяца, год; ориентировочный ИМТ с оговоркой.
- Все данные здоровья видит только владелец: правила базы (RLS) не отдают чужие строки никому, включая тренера. На публичных страницах они не показываются.
- Активность (`/profile/activity`): завершённые занятия из журнала, серии, календарь 12 недель, занятия по неделям. Только реальные отметки «я сделал(а)», никаких оценок калорий или пульса.

## Чего нет и почему

Шаги, пульс, сон и калории с Apple Watch доступны только через HealthKit, а HealthKit открыт только нативному iOS-приложению. Из сайта в браузере, даже добавленного на экран «Домой», до него не дотянуться. Поэтому кнопки «Подключить Apple Health» в веб-версии нет: она была бы обманом.

## Архитектура, когда дойдём

1. **Нативная оболочка уже есть** (Capacitor, папка `ios/`). В неё ставится плагин HealthKit, например `@perfood/capacitor-healthkit` или `capacitor-health`. Это бесплатно.
2. **Разрешения по одному.** Экран в приложении перечисляет типы данных: шаги, тренировки, активная энергия, пульс, сон. Пользователь включает каждый отдельно, с пояснением зачем. iOS показывает свой системный диалог. Без разрешения тип не читается.
3. **Чтение на устройстве.** Приложение читает разрешённые данные локально и показывает в «Моём здоровье» и «Активности». Статус каждого типа: «подключено», «нет разрешения», «недоступно на этом устройстве».
4. **Отправка на сервер только по согласию.** По умолчанию данные Apple Health остаются на телефоне. Если пользователь явно включит «сохранять в аккаунт», сводные значения за день пишутся в отдельную таблицу `health_daily` с теми же правилами доступа «только владелец».
5. **Apple Watch отдельно не нужен**: часы пишут в Health на iPhone, приложение читает оттуда. Собственное приложение для часов понадобится только для запуска тренировок с запястья, это далёкая перспектива.
6. **Android**: аналог через Health Connect, тем же плагином или соседним.

## Требования App Store для этого

- В `Info.plist` строки `NSHealthShareUsageDescription` и `NSHealthUpdateUsageDescription` с понятным объяснением.
- Политика конфиденциальности с разделом о данных здоровья.
- При проверке Apple смотрит, что приложение действительно использует данные, которые запрашивает.

## Порядок внедрения

1. Собрать iOS-приложение в Xcode и убедиться, что оболочка работает.
2. Добавить плагин HealthKit, экран разрешений, чтение шагов и тренировок.
3. Показать данные в «Моём здоровье» со статусом подключения.
4. Опционально: сохранение сводок в аккаунт по согласию.
